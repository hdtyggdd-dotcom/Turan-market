name: AI advice billing
description: Billing choice and failure transparency for marketplace AI advice.
---

Use the owner's own Anthropic API access for market advice. Do not retry managed AI setup or switch this feature to Replit credit billing without an explicit new request.

**Why:** The owner chose their own API key rather than managed AI access when the advice connection was repaired.

**How to apply:** Request replacement credentials only through the secure secrets flow. Distinguish authentication failures from an insufficient provider API balance; neither is repaired by substituting canned advice and labeling it AI.
